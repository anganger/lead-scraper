# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and respectful, assume good intent, give and take feedback gracefully, and keep discussion about the work. Harassment, insults, and sharing other people's private information are not accepted.

## Reporting

If someone's behaviour worries you, report it privately to the maintainer through a
[private security advisory](https://github.com/anganger/lead-scraper/security/advisories/new)
(it reaches only the maintainer) instead of a public issue. Reports are handled confidentially.

Maintainers may remove comments, code or contributors that break these rules.
